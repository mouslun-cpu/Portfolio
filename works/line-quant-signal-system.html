LINE 量化訊號推播系統

2026.07 · 個人專案
FIG. 36 — 產品主畫面
關於這個作品

LINE 量化訊號推播系統將台股 scanner 的每日結果收斂為可行動的訊號摘要。

排程會彙整多個 scanner 的共振標的、寫入 PostgreSQL，並透過 LINE 發送每日訊號與週報；後續再以實際推播紀錄追蹤出場後表現，形成策略研究的回饋迴圈。

作品亮點
每日彙整多個 scanner，標出共振訊號
GitHub Actions 自動執行推播與週報流程
保留實際推播紀錄，回收 OOS 績效作為研究回饋
