開一間咖啡廳學成本

2026.04 · 個人專案
FIG. 53 — 產品主畫面
關於這個作品

這是一個多人同步的咖啡廳經營模擬。學生以老闆與合夥人的角色組隊，依序決定店型、咖啡豆、乳品、售價與行銷預算，並觀察決策如何改變銷量、成本與資金。

教師可透過 QR Code 開場、控制關卡與月份進度，並在 Dashboard 比較各組每月損益、資本變化與最終經營成果。

作品亮點
選址、原料、售價與行銷預算的連動決策
直接成本、固定成本、營收與損益即時呈現
老師以 QR Code 建場並控制關卡與月份
全班 Dashboard 比較各組決策與獲利表現
